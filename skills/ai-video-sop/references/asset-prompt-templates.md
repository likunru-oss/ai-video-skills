# 资产图提示词模板（Nano Banana Pro，16:9，文生图）

人物三视图不在这里，一律用 `~/.claude/skills/character-sheet/SKILL.md` 的固定模板。
下面是车辆（T）、道具（P）、场景（E）三种。原文样板见 `gold-asset-prompts.md`。

## 共同规则

- 每条一个代码块，全中文。
- 开头固定"超高清真实摄影质感，8K，<车辆设定图 / 道具设定图 / 环境概念图>。"
- 写可画出来的物理细节：颜色、材质、结构、使用痕迹、相对高矮和大小（后面镜头要靠它判断能不能过、谁更高）。
- 所有可能带标的地方都写"无任何车标 / 无品牌"。
- 牌子、贴纸、车身上要出现的短文字和数字直接印上去（A 类），同时给一个空白备用版，写法见 `post-minimization.md` 第二节；没有指定文字的牌面写"空白"。
- 不写浅景深。环境图可以写"景深中等"。
- 结尾固定一句真实摄影声明 + "非CG" 或 "无任何文字和品牌"；有指定文字时写"无任何品牌，除指定文字外无任何文字"。

## T · 车辆多视图

```
超高清真实摄影质感，8K，车辆设定图。一辆<颜色><地区><车型>，<车身特征：腰线/货箱/改装>，<车漆使用痕迹>，通用车头造型：<格栅/车灯形状>，无任何车标，无品牌字样<，无引擎盖立标>，<排气管/天线/后视镜等关键结构>。<挂车/货箱/后座：颜色、材质、尺寸、干净无任何文字，和车头的高度关系>。车牌位置空白。纯浅灰色影棚背景，柔和大面积影棚光。同一画面中排列正前方、正侧面<（含完整挂车）>、3/4前侧、正后方四个视图，车辆比例和细节完全一致。真实商业汽车摄影，非CG。
```

两轮车、自行车、电动车同样适用，把视图换成"正前方、正左侧、3/4前侧、正后方"，并写清车筐、外卖箱、挡泥板等附件。

## P · 道具图

```
超高清真实摄影质感，8K，道具设定图。一<量词><道具名>，<外壳材质和颜色>，<正面部件：按钮/旋钮/屏幕（显示内容空白）/指示灯>，<连接件：线缆/挂钩/支架>，<使用痕迹>。<道具>上没有任何品牌和文字。同一画面中展示：<正面>、<安装或佩戴在什么位置的样子>、<静止状态>、<后面镜头要用到的关键动作状态，如被拿起、打开、亮起>。纯浅灰色影棚背景，柔和影棚光。真实产品摄影，非CG。
```

手机、导航支架这类屏幕道具：屏幕一律"黑屏"或"显示内容空白"，真实界面在视频生成里绑定物料位截图。

## E · 环境概念图

```
超高清真实摄影质感，8K，环境概念图。<国家/地区><地点类型>，<主要结构：道路走向、建筑、桥、路口、岔路，写清在画面左/右/前/后>，<后面镜头要用到的关键物：积水、施工桶、招牌（牌面空白）、限高牌（牌面空白）>，<材质和使用痕迹：水渍、锈迹、裂缝>。没有车辆和行人。<时间和天气>，<主光方向和颜色>，<阴影/反光>。<景别和机位>构图，<引导线指向哪里>。真实纪实摄影，<夜景/雨夜>，无任何文字和品牌。
```

室内（驾驶室、店内、家里）：

```
超高清真实摄影质感，8K，环境概念图。<地点>内部，从<哪个位置>向<哪个方向>看，能同时看到<座位/台面>。<关键道具和位置>。<贴纸/屏幕（纸面空白/显示内容空白）>。<窗外是什么>。<座位空着/没有人物>。<光从哪里、什么颜色射进来>。中景构图，景深中等。真实纪实摄影，无任何品牌标志和文字。
```

同一场景需要白天和夜晚两个版本时，分成 E1、E2 两条，结构描述逐字相同，只改时间光线句。
