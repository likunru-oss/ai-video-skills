# AI Video Skills · AI 视频制作 SOP

一套 AI 视频制作 skill（技能包），支持 [Claude Code](https://claude.com/claude-code)、ChatGPT、WorkBuddy 等平台：把任何故事、剧本或一句想法，变成一整套**可以直接执行**的 AI 视频制作包——人物和场景的出图提示词、[Seedance 2.5](https://seed.bytedance.com/) 全能参考模式的视频提示词、剪映操作清单和上线前对照清单。

> An Agent Skills pack (Claude Code, ChatGPT, WorkBuddy and more) that turns any story or one-line idea into a ready-to-shoot AI video production package (Chinese-first).
> （一套遵循 Agent Skills 标准的技能包，可用于 Claude Code、ChatGPT、WorkBuddy 等平台，把任何故事或一句想法变成可以直接开拍的 AI 视频制作包，以中文为主。）

## 简介

| 你给它 | 它给你 |
|---|---|
| 一句想法，比如"一个外卖骑手雨夜送餐，导航带他绕开积水路段，15 秒" | 一个 markdown 制作包：脚本镜头表、品牌风险清单、一致性锚点、所有资产图提示词、按剪辑点分好条的视频提示词、剪映操作清单、上线前对照清单 |

仓库里有两个 skill：

| skill | 作用 |
|---|---|
| `ai-video-sop` | 主流程：从需求到制作包的全部步骤 |
| `character-sheet` | 人物三视图提示词（右侧头部特写 + 左侧正面、背面全身），`ai-video-sop` 会自动调用它 |

### 三种模式，自动判断

| 模式 | 适合 | 交付 |
|---|---|---|
| **广告模式**（默认） | 15–60 秒信息流广告、App 推广、故事型广告 | 一个制作包文件，默认 9:16 |
| **TVC 模式** | 电视广告、产品广告、品牌片，自家产品要出镜 | 一个制作包文件，默认 16:9，含 15 秒剪短版和电视交付规格 |
| **短片模式** | 1–10 分钟叙事短片、微电影、短剧 | 先出总纲（大纲、分场表、角色服装表、资产），确认后每场一个文件 |

## 特色

### ★ 画面会根据内容自动分配合适的电影风格化提示词

你不用懂摄影，也不用自己挑风格。每一条视频提示词开头都有一句"色彩句"，skill 会**根据这一段的内容自动分配**：

1. **读内容：** 这一段的情绪（紧张、温暖、孤独、轻松、悬疑、热血）、时段和天气（清晨、正午、黄昏、夜、雨）、地点（公路、城市、室内、海边）、题材（广告、产品、剧情、喜剧）。
2. **配风格：** 从内置的十几套电影风格里选最合适的一套，写明相机色彩（例如 ARRI Alexa 胶片感）、参考影片和色彩走向——高光、中间调、暗部、天空、肤色分别往哪偏。
3. **前后统一：** 同一条故事线用同一套风格；需要对比的两条线（出事 / 解决、回忆 / 现实）自动用两套反差明显的风格。
4. **光线跟着风格走：** 每个镜头的光线都用影视专业用语写——光源位置和角度、色温、软硬、光比、丁达尔光出现在画面哪里、脸上是伦勃朗光还是蝴蝶光、眼神光。

举例：

| 内容 | 自动分配的风格 |
|---|---|
| 城市雨夜、骑手遇到积水 | 参考《夜行者》：钠灯高光偏橙，暗部青黑，高反差 |
| 绕开积水、温暖送达 | 参考《花样年华》：门廊灯高光偏琥珀，暗部深褐，中低反差 |
| 公路夜色、老司机怀旧 | 参考《德州巴黎》：钠灯橙、暗部深青绿、夜空墨蓝 |
| 产品片、清晨咖啡 | 参考《无依之地》：高光暖金，天空清透青蓝，低反差 |
| 喜剧、明快 | 参考《布达佩斯大饭店》：粉黄高光，色块分明 |

### 其他特色

- **多镜头合成一条生成，按剪辑点切条：** 每条 10–15 秒，由几个完整镜头组成，不会出现"镜头拍到一半就停了"再靠下一条去接。
- **时间块以人物动作为主线：** 每个镜头只交代景别、机位方向和高低、一种运动，再按秒写动作，结尾写"镜头结束在……"。细节够模型照着做，又留了发挥空间，抽卡次数少。
- **用具体的物理描写，不用比喻：** 不写"像开罐头一样"，而是写哪个部位、怎么变形、多大、多快、最后停成什么样。
- **一致性锚点：** 每个人物、车辆、道具、场景都有固定名字，参考图写成 `固定名字：@图片N，锁定……`，正文一律用全名，人和物不会换脸、换样子。
- **后期最小化：** 牌子上的数字直接生成；包装大字、结尾画面、角标用 Nano Banana 直接出成品图；剩下的只留剪映里点一下就完成的操作。
- **人物三视图固定模板：** 脸部按固定顺序写细，只留一个辨识特征，原创面孔，衣服无品牌。
- **每条都带专属负面提示词**，符合 Seedance 2.5 的限制（时长档位、最多 9 张图）。
- **品牌风险清单：** 按高、中、低列出，每条写怎么处理，并在上线前对照清单里逐条检查。
- **"故事"一节放在最前面：** 脚本前先用 3–5 句大白话讲清片子讲了什么，再写一句"要传达的"，没看过脚本的人也能一眼看懂。
- **完整版和团队版分开：** 本地制作包是完整版；提示词逐条贴在聊天里方便复制；同步到 Notion、网页、在线文档的是团队版，只放故事、脚本、品牌风险、锚点、清单、剪映步骤和对照，不放任何提示词。
- **15 秒广告自动精简：** 最多 6–7 段，每个 AI 镜头不短于 2 秒，生成多少就用多少，剪出来正好 15 秒。
- **少用第一视角：** 驾驶室主观视角最难生成，默认改用车外固定机位、越肩或低机位。
- **故事有真实依据：** 每个故事都写一段"真实依据"（真实案例、新闻、法规或可对照的地点），数字先核实再写。
- **开头 0–2 秒抓人：** 痛点型广告开头先给损失或麻烦，功能型广告有自然的钩子就放最前。
- **App 画面在生成里做：** 手指点按和屏幕切换写进视频提示词，屏幕内容绑定你提供的截图（物料位），不用再拼录屏。
- **人物可以露脸：** 只演戏，不对着镜头做证言，配音放画外。
- **全中文输出：** 所有英文台词、字幕都附中文翻译。

## 使用流程

### 1. 说出你的想法

直接用一句话描述，或者输入 `/ai-video-sop` 加上你的故事。例如：

> 做一条 15 秒的竖版广告：一个外卖骑手雨夜送餐，导航带他绕开积水路段。

> 帮我把这个故事做成 5 分钟短片：一位老卡车司机退休前的最后一个夜班……

> 做一条 30 秒的保温杯 TVC，产品照片我等下发你。

### 2. 回答缺的几个问题

skill 只问推不出来又会明显影响结果的项（时长、比例、画风、平台、人物、品牌限制、视频工具），一次问完。其他用默认值，并在制作包开头列出来，随时可以改。

### 3. 拿到制作包

广告模式和 TVC 模式是一个 markdown 文件，包含：

1. 故事（3–5 句大白话 + 要传达的）+ 脚本镜头表 + 品牌风险清单
2. 一致性锚点（每个人物、车辆、道具、场景的固定名字）
3. 产出物清单
4. 资产图提示词：人物三视图（C）、车辆（T）、道具（P）、场景（E）、产品（PR，TVC 用）、成品字卡和结尾画面（W）
5. 视频提示词：每条一个代码块，写好上传顺序
6. 需要你提供的物料位（App 截图）和配音
7. 剪映操作清单
8. 上线前对照清单

短片模式先给 `00-总纲.md`，你确认故事大纲和分场表后，再一批一批地写 `场01-….md`、`场02-….md`，最后是 `99-剪辑与交付.md`。

所有提示词也会逐条贴在聊天里，一条一个代码块，直接复制就能用。需要给团队看时，可以让它同步一份不含提示词的团队版到 Notion。

### 4. 出资产图（Nano Banana Pro）

把第四部分的提示词逐条复制到 Nano Banana Pro，比例 16:9（字卡、结尾画面按成片比例）。带字的牌子会给"带字版"和"空白备用版"两张。

### 5. 生成视频（Seedance 2.5 全能参考）

每条视频提示词上方写了**上传顺序**。按顺序上传资产图，它们会自动编号为 @图片1、@图片2……，然后把整个代码块（包括末尾的负面提示词）粘贴进去，时长选提示词开头写的秒数。

### 6. 剪辑（剪映）

照第七部分的剪映操作清单一步一步做：每一步都写明了用哪条视频、放哪张图、点哪里。

### 7. 上线前检查

照第八部分的清单逐条打勾。

## 注意事项

- 人物都是 AI 原创面孔，提示词里写明"不像任何真实名人"；画面里默认不出现任何别家品牌、车标和真实车牌。
- App 画面在视频生成里做：手指点按和屏幕切换写进提示词，屏幕内容绑定你提供的 App 截图（物料位 M1、M2…），不再拼接整段录屏；屏幕文字变形时再退回真实录屏。
- 配音请用签约配音演员或有授权的合成声线。
- 涉及功效、数据、时长的宣传语，上线前请准备好依据。
- 生成效果会随模型版本变化，提示词里写的是"让模型更容易做对"的写法，不保证一次成功。

## 关于样板

`references/` 里的样板都是虚构示例，只用来展示写法：外卖骑手雨夜绕行（广告）、保温杯下午四点（TVC）、老司机最后一趟（短片）。
