# 视频提示词标准（Seedance 2.0 全能参考）

以 `gold-video-prompts.md` 的样板为准：结构、动作主导的时间块、光线深度、色彩句、负面提示词都要对齐它。这份文件把它拆成可照着写的规则。

## 一、Seedance 2.0 限制

| 项 | 限制 |
|---|---|
| 时长 | 只能 4 / 5 / 6 / 8 / 10 / 12 / 15 秒 |
| 图片 | 每条最多 9 张，建议 4–6 张 |
| 视频 / 音频参考 | 最多 3 段 / 3 段 |
| 编号 | 按上传顺序自动编号 @图片1、@图片2……；每条单独写上传顺序，从 @图片1 起 |
| 台词 | 提示词里写英文原句加引号，并写声线 |

## 二、分组（按剪辑点切条）

**核心规则：每条生成都从一个剪辑点开始、到一个剪辑点结束，由几个完整的镜头组成。** 不把一个镜头拆到两条生成里，也不让生成在动作中间停掉、再靠下一条去接。

1. **先找剪辑点再分条。** 按镜头表顺序往下数，在镜头和镜头之间的硬切处断开，让每条落在 **10–15 秒**（10 / 12 / 15 档）。整片或整段本来就短（比如 15 秒广告的一段只有 6 秒），才用 4–8 档。
2. **让镜头时长之和正好等于档位。** 分完以后，在每个镜头 ±0.5–1 秒的范围内微调时长，凑成 10、12 或 15 秒。生成多少秒就用多少秒，不靠"多生成几秒、后期裁掉"来凑档位。
3. **最后一个镜头留余量。** 最后一个镜头里的动作在结束前约 0.5–1 秒完成，然后写"保持……至 N 秒"，让模型不会在动作中间截断。
4. **一个镜头太长就拆成两个镜头。** 单镜头超过约 6 秒、或者一个连续动作装不进一条时，在动作中间加一个反应镜头、插入特写，或者换景别硬切，变成两个完整镜头。**不用末帧接力**来硬接一个长镜头。
5. **同一条里放什么：** 同一条故事线、同一时段、同一组参考图的连续镜头。单条一般 2–5 个镜头，单镜头 1.5–5 秒；最后一个镜头带"保持"时可以到 7 秒左右。
6. **不进视频提示词的：** 倒卷、白闪、包装大字、定格都在后期做。App 操作和屏幕切换要写进视频提示词，屏幕内容绑定物料位截图。
7. **多条故事线交叉剪：** 每条线各自生成，后期交叉剪；同一个路口、同一个机位的"对照镜头"在两条里写成相同的机位、高度和构图。

**分组表（写在视频部分开头）**：每条列出起止剪辑点、包含的镜头和每个镜头的时长，加起来正好等于档位。例如：

| 条 | 档位 | 镜头（时长） | 起止剪辑点 |
|---|---|---|---|
| V1 | 12 秒 | S1（3）+ S2（4）+ S3（5） | S1 开头 → S3 结尾硬切 S4 |
| V2 | 15 秒 | S4（4）+ S5（3）+ S6（3）+ S7（5） | S4 开头 → S7 结尾 |

## 三、代码块内部结构（顺序固定）

### 1. 开头句

`<N>秒，<几>个镜头，全部硬切。0—<t1>秒<镜1内容>；<t1>秒硬切<镜2内容>；……，保持至<N>秒。`
- 每个切点写秒数，最后一镜写"保持至 N 秒"。
- 切点必须和下面时间块一一对应。

### 2. 色彩句（约 60–80 字，紧跟开头句）

格式：`写实电影质感，ARRI Alexa <胶片感/自然> 色彩，色调走向参考《<影片>》的<一个词概括>：高光偏<>、中间调<>、暗部偏<>，天空<>，肤色<>，整体<饱和度/反差/明暗>。节奏<>。`

**电影风格自动分配：** 不让用户挑风格，按内容自动给每条生成分配一套电影风格。顺序：
1. **读内容：** 这条生成的情绪（紧张 / 温暖 / 孤独 / 轻松 / 悬疑 / 热血）、时段和天气（清晨 / 正午 / 黄昏 / 夜 / 雨）、地点（公路 / 城市 / 室内 / 乡村 / 海边）、题材（广告 / 产品 / 剧情 / 喜剧）。
2. **配一套风格：** 从下表选最接近的一行，定下相机色彩（ARRI Alexa 胶片感 / 自然）、参考片、色彩走向；参考片只用来指色调，不写剧情。
3. **同一条线保持一致：** 同一条故事线、同一个时段的几条生成用同一句色彩句；对比的两条线（出事线 / 解决线、回忆 / 现实）用两套明显不同的风格。
4. **光线跟着风格走：** 逐镜头光线段的色温、光比、反差要和色彩句的走向一致（压抑线光比大、暗部深；轻松线光比小、低反差）。
5. **全片不重复用同一部参考片做相反的情绪**；同一个项目里风格总数控制在 3 套以内。

### 3. 参考绑定

```
参考绑定：
<固定名字>：@图片1，锁定<这张图要锁的具体内容：身份、脸、体型、哪件衣服 / 外观、比例、无车标 / 结构、光线>；
<固定名字>：@图片2，锁定……；
```
- 每个 @图片N 只在这里出现一次，最后一行用句号。
- 只锁这一条需要的部分（只出现手就写"锁定手、肤色和袖口"）。
- 固定名字和一致性锚点、其他各条完全相同。

### 4. 空间固定

写：道路/轴线方向、每个对象的左右前后位置、行进方向、谁在前谁在后、距离（米）、相对高度、左舵右舵与座位、太阳或主光在哪一侧、**整段不存在什么**（其他车、行人、火车）。

### 5. 时间块（动作主导）

每个时间块是一段话，**以人物（或主体）的动作为主线**，镜头只交代必要的三件事，其余构图细节留给模型发挥。

```
<t0>—<t1>秒：
<硬切><景别>，<机位：从哪个方向拍、高还是低、平视 / 俯 / 仰>，<运动：固定 / 推 / 拉 / 跟 / 升 / 摇中的一种，快还是慢>。<主体用固定全名，按节拍写动作：约 x 秒做什么，哪只手、往哪个方向、动多大、停成什么样>。<镜头结束在什么状态>。
```

**要写的：**
- 镜头三件事：景别、机位方向和高低、一种运动。
- 动作按节拍写，带大致秒数；动作本身按"具体物理描写"的规则写清楚（哪个部位、方向、距离、速度、停下的样子、二次运动）。
- 结尾一句"镜头结束在……"，让模型知道停在哪，切点才准。
- 左右容易搞反时（转弯方向、行驶方向、人物朝向），补一句画面左右，例如"车头转向画面左侧"。
- 需要给后期留位置时（上方留天空放字）、或者构图本身就是剧情时，才写构图。

**不用写的（留给模型）：** 焦段、景深、画框上下沿在哪、主体占画面百分比、前景中景背景逐层清单。

**提高成片率的规则：**
1. **一镜一个主动作。** 一个镜头里最多两个动作节拍同时发生；两个人都要动时，错开先后。
2. **一镜一种运动。** 不写"推 + 摇 + 升"组合。
3. **单镜头不短于约 1.5 秒**，一条生成不超过约 5 个镜头。更快的节奏靠后期剪短。
4. **避开模型弱项，或者拆开拍：** 交叉换手、手指精细操作超过两步、多人肢体接触、快速 360 度环绕、镜子里的清晰倒影、运动中的文字、快速转身。
5. **相邻两个镜头要明显不同**（至少差一档景别，或者机位换一个方向），模型才会真的切开。
6. **尽量不用第一视角。** 驾驶室主观视角、挡风玻璃视角这类镜头整个世界都在动，画面里没有固定的主体，模型最容易画乱。默认改成下面三种：
   - **车外固定机位：** 摄影机不动，车辆从画面一侧开进来、开向目标（桥洞、车位、路口）。
   - **越肩：** 摄影机在卧铺口，画面里有驾驶座椅背或司机肩背和驾驶室内部，挡风玻璃外只是背景。
   - **车外低机位 / 侧面：** 贴地从侧面拍车轮、挂车顶、车头开进去或撞上去的那一下。
   只有明确需要第一视角时才写；写的时候只说车辆做什么，不写周围景物从画面两侧掠过。

### 6. 连续性

标题用"连续性："或"人物与动作连续性："。写：每人一个完整身体、坐哪里、哪只手始终在哪里；同一道具、同一车辆；关键动作只发生一次；方向始终一致；损坏位置一致；画面无文字/车标/品牌/车牌，牌面空白后期加。

### 7. 光线（逐镜头）

先一段总光：天气、主光源、高度角和方位（相对拍摄对象或画面）、色温 K、软硬、整体调色（饱和度百分比、暗部色调、高光、黑位）。然后每个时间块一行 `<t0>—<t1>秒：`，从下面词汇里选用：

| 维度 | 写法 |
|---|---|
| 光源位置 | 太阳高度约 35°，位于画面右前方；从画面左侧约 60° 打在…… |
| 色温 | 5200K 日光、2000K 钠灯、3200K 钨丝、6000K 车灯、4000K 荧光、霓虹品红/青 |
| 软硬 | 硬光（锐利投影）/ 柔光（大面积天空光、阴天、雨夜漫射） |
| 光比 | 1:2（柔和）/ 1:4 / 1:6 / 1:8 / 1:16（夜景高反差） |
| 曝光取舍 | 按亮部曝光，暗部欠曝约 3 档；背景天光过曝约 2 档；牌面不过曝 |
| 丁达尔光 | 写在画面哪个区域、由什么形成（枕木缝隙、侧窗、车灯穿过雨幕/薄雾、浮尘、热气、水汽），持续多久 |
| 脸部布光 | 伦勃朗光（暗侧颧骨下三角亮区）、蝴蝶光（鼻下蝶形阴影）、环形光、分割光、轮廓光 |
| 眼神光 | 挡风玻璃形状的长方形眼神光、手机屏幕的小方形眼神光、霓虹点状眼神光 |
| 实际光源 | 仪表灯、转向灯、屏幕、招牌、路灯、尾灯，以及它们在什么表面映出什么颜色 |
| 反射 | 湿路面倒影、镜面高光、金属边缘高光 |

### 8. 声音（逐秒）

`声音：0—x秒<环境声>；约 x 秒<拟音>；……` 
- 台词：`约 x—y 秒，<人物固定名字><语气>地说："<English line>" 声音是<年龄><性别><地区口音>，语气<>、音量<>，来自<画面位置>。`
- 有台词时写"只说指定台词，不另读中文翻译"。
- 结尾按需要写"无旁白、无音乐、无字幕"。配乐都在后期铺，视频里一律不生成背景音乐。

### 9. 负面提示词

`负面提示词：<本条专属不要项>、<通用不要项>。`

- **专属项**：这一条最容易出错的东西——错误方向（右转/掉头）、不该发生的动作（重复撞击、撞击过程）、不该出现的物体（火车、警车、其他车辆）、伤害（血迹、人员受伤）、不该有的光线（白天光线、阴沉色调）、正脸（侧影镜头）、驾驶中双手离开方向盘。
- **画面里有指定文字的条**（A 类，见 `post-minimization.md`）：通用项里的"文字、字幕"换成 `除"<指定文字>"以外的任何文字、文字变形、错别字、字符增减、字幕`。
- **通用项（每条都带）**：人物换脸、换装、多余的人、多余的手、多余手指、手指变形、文字、字幕、水印、logo、车标、品牌标志、车牌、手机（除非剧情需要）、卡通感、CG感、塑料质感、过度锐化、过饱和、画面闪烁、帧间跳变、背景音乐、旁白。

## 四、抽卡失败先改哪里

| 生成出来的问题 | 先改提示词的哪里 |
|---|---|
| 镜头没按切点切，或者两个镜头合成一个 | 开头句的切点和时间块是否一致；两个镜头的景别、机位差得够不够大（至少差一档景别或 45 度方位） |
| 镜头不动，或者乱动 | 是否只写了一种运动；固定镜头是否写了"固定"；需要时加一个快慢 |
| 动作做了两遍，或者做到一半 | 节拍秒数是否合理；是否写了"镜头结束在……"；连续性段是否写"只发生一次" |
| 人物左右手、朝向错了 | 空间固定段是否说清摄影机在人物哪一侧；这个动作是否补了画面左右 |
| 人物变脸、换衣服 | 参考绑定是否锁了"完整身份"和服装；这条参考图是否太多（超过 6 张时删掉不出现的） |
| 构图和想的不一样 | 只在这个镜头补一句构图（主体在画面哪一侧、留白在哪），别的镜头不加 |
| 产品或道具变形 | 这个镜头是否离产品太近又在快速运动；把运动改成固定或慢推 |

每次只改一处再重抽，才知道是哪一处起了作用。

## 五、禁止写法

| 不要写 | 改成 |
|---|---|
| 车顶像开罐头一样卷起 | 挂车顶部银色铝皮从前沿被撕开，向后翻卷起约三米长、半米宽的一条，边缘锯齿状，向上翘成弧形 |
| 水花像烟花一样炸开 | 前轮压进约 10 厘米深的积水，向两侧溅起约 1 米高、2 米宽的扇形水帘，0.5 秒内落回路面 |
| 他仿佛松了一口气 | 他肩膀下沉约 3 厘米，胸口起伏一次，长长呼出一口气 |
| 那辆车 / 他 / 卡车 | 用固定全名：白色长头牵引车 / 黄色雨衣骑手 |
| {{Mixed 1}} / 参考图1 / 正文里的 @图片1 | 只在绑定段写 `名字：@图片1`，正文写全名 |
| 一个镜头一条 3 秒视频 | 多镜头合成一条，镜头间写硬切 |

## 六、自查（每条 V 写完都过一遍）

- [ ] 时长在档位内；镜头时间加起来正好等于总时长；开头句切点和时间块一致
- [ ] 这条从一个剪辑点开始、到一个剪辑点结束，没有哪个镜头被拆到别的条里；最后一个镜头的动作在结束前完成，后面是"保持"
- [ ] 上传顺序单独列出，@图片1 起连续编号，≤9 张
- [ ] 色彩句有相机、参考片、高光、中间调、暗部、天空、肤色、整体
- [ ] 每个 @图片N 只出现一次；正文全用固定全名
- [ ] 每个时间块以动作为主线；写了景别、机位方向和高低、一种运动；结尾写了"镜头结束在……"
- [ ] 一镜一个主动作、一种运动；单镜头 ≥ 约 1.5 秒；一条 ≤ 约 5 个镜头
