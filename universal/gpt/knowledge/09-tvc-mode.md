# TVC 模式（电视广告 / 产品广告 / 品牌片）

TVC 模式照 SKILL.md 的 9 步和 `package-template.md` 走，视频提示词仍然完全按 `video-prompt-standard.md` 和 `gold-video-prompts.md` 样板写。下面只写**和广告模式不一样的地方**，没写到的一律按广告模式。

不做多宫格、关键帧和分阶段（Phase）格式。

---

## 一、品牌规则（替换广告模式的"无品牌"）

| 对象 | 规则 |
|---|---|
| 自家产品、包装、标志、品牌色 | 可以出现，而且要准确。外观以真实产品照片为准，不让 AI 自己编 |
| 别家品牌（车、手机、衣服、饮料、街边招牌） | 一律不出现，照旧写"无任何标志 / 无品牌 / 招牌空白" |
| 产品上的小字、标志 | AI 视频画不准小字。近景和特写里的标志、产品名、成分表，提示词里写"标志位置保持原样、不要重画"，后期用真实素材贴合或替换；做不到就让这一面不朝镜头 |
| 结尾产品定版 | 默认后期用真实产品照片或三维渲染合成，不交给 AI 生成；AI 只生成定版背景和光效 |
| 广告语、价格、功能承诺 | 写进品牌风险清单：功效、对比、"最""第一"等绝对化用语、价格时效、需要标注的法律小字 |

## 二、需求收集要多问的

- **真实产品照片：** 必须有。最好是白底的正面、侧面、背面、45°、顶面，外加包装和使用状态各一张。没有就停下来问，不用文生图编产品。
- **品牌规范：** 标志用法、品牌色色号、字体、不能做的事（比如不能倒放、不能和食物同框）。
- **投放版本：** 主版时长（30 / 60 秒）和剪短版（15 / 6 秒）。
- **法务小字：** 需要出现的声明、条款、"图片仅供参考"一类。

## 三、资产（在 C / T / P / E 之外加 PR）

| 编号 | 类型 | 说明 |
|---|---|---|
| PR1… | 产品参考图 | **首选：**直接用真实产品照片当参考图，不生成。<br>**只有一两张照片时：**用 Nano Banana Pro 编辑模式，上传真实照片，补出多视图（模板见下） |
| P / E | 道具、场景 | 广告模式的模板照用；品牌片的场景可以带品牌色，但不出现品牌字 |
| C | 人物 | `character-sheet.md` 模板不变 |

### PR · 产品多视图（编辑模式，上传真实产品照片）

```
以上传的产品照片为唯一依据，生成产品设定图。保持产品的外形、比例、颜色、材质、按键和接口位置、标志位置和标志图形与照片完全一致，不改动、不重画、不添加任何部件和文字。同一画面中排列正前方、正侧面、3/4前侧、正后方、顶面五个视图，产品比例和细节完全一致。<材质描述：磨砂铝、亮面玻璃、软胶、纸盒的具体质感>。纯浅灰色影棚背景，柔和大面积影棚光，无反光干扰标志区域。真实商业产品摄影，非CG。
```

> 编辑模式出来的小字仍然可能变形。视频绑定里用这张图锁外形，标志和小字照旧靠后期。

## 四、产品镜头写法（写进视频提示词的时间块和光线段）

产品镜头和人物镜头一样，按 `video-prompt-standard.md` 的物理描写写：位置、尺寸、角度、速度、停成什么样。常用镜头：

| 镜头 | 时间块里要写清 | 光线要写清 |
|---|---|---|
| **产品亮相（hero shot，英雄镜头）** | 产品在画面中的位置和占比；摄影机绕产品转多少度、用几秒；产品是否转动、转多少度 | 主光方向和面积（大柔光箱 / 条形灯）；产品边缘的轮廓光；黑旗压暗哪一侧；背景渐变 |
| **材质微距** | 微距距离（厘米）；对焦平面在哪个部位；焦点从哪里移到哪里、用几秒 | 掠射光角度（10°–20° 贴着表面打出纹理）；高光条的位置和宽度 |
| **功能演示** | 哪只手、哪根手指按哪里、按下多深；产品发生什么可见变化（灯亮、盖子弹开 3 厘米） | 实际光源（屏幕、指示灯）的颜色和映在哪里 |
| **使用场景** | 人物拿产品的手势、产品朝向镜头的一面（标志那面朝镜头还是避开） | 和人物同一套布光，产品上额外一条反光板或高光 |
| **液体 / 粉末 / 烟雾** | 量（毫升 / 厘米高）、流速、方向、落点、停下后的形状 | 背光或侧逆光把液体打透，写清透光的颜色 |
| **定版背景** | 产品位置留空（后期合成），画面哪一块干净留给标志和广告语 | 背景光的颜色、渐变方向，和品牌色一致 |

产品镜头专属负面提示词（加在通用项前面）：`产品变形、产品比例错误、按键或接口位置改变、标志变形或乱码、额外的文字、产品颜色偏差、多出的产品、别家品牌、反光遮住标志`。

## 五、视频分组

- 仍然按剪辑点切条（`video-prompt-standard.md` 第二节）：每条由完整镜头组成，镜头时长之和正好等于档位，生成多少秒就用多少秒。
- 30 秒大约 3 条生成，60 秒大约 5–6 条。成片里 AI 镜头的总时长 = 各条档位之和，剩下的时间留给后期做的定版和包装。
- 产品镜头的组通常比较短，可以用 8 秒或更短的档位，不要为了凑到 10 秒硬加镜头。
- 一条生成里的镜头可以在成片里不相邻：后期按镜头表把各条的镜头穿插着剪。
- 产品镜头和人物剧情镜头**分开成组**：产品镜头一条（参考图只放 PR 和必要的 E），剧情镜头另一条。混在一起时，模型容易把产品画走样。
- 每条产品镜头的生成，参考绑定里写"<产品固定名字>：@图片N，锁定外形、比例、颜色、材质、按键位置和标志位置，不重画标志和文字；"。

## 六、后期最小化

按 `post-minimization.md` 分 A / B / C。TVC 的特殊点：
- 自家标志和产品小字仍然不让视频模型画（第一节的规则优先），用 W 图或真实素材贴。
- 广告语、法务小字、结尾定版做成 W 图：结尾定版用编辑模式上传真实产品照片和标志，一张图排好。

## 七、交付规格（替换广告模式的第六、七部分里的规格行）

- **画面：** 16:9，1920×1080 或 3840×2160，25 或 29.97 帧，按投放地区。
- **安全框：** 重要画面在动作安全框（画面 93%）内，所有字幕、标志、法务小字在字幕安全框（画面 90%）内。
- **响度：** 按投放地区标准。美国 −24 LKFS（ATSC A/85），欧洲 −23 LUFS（EBU R128），国内按电视台要求。
- **版本：** 主版 + 剪短版各一份，剪短版在剪映操作清单里单独列出用哪些镜头。
- **法务小字：** 停留时长和字号按法务要求，做进 W 图。

## 八、上线前对照（在广告模式清单上加）

- [ ] 产品外形、颜色、按键、标志位置和真实产品一致
- [ ] 标志和小字是后期贴的真实素材，没有 AI 画出的乱码
- [ ] 结尾定版用的是真实产品图或三维渲染
- [ ] 没有别家品牌
- [ ] 广告语没有绝对化用语，功效和对比有依据
- [ ] 法务小字齐全，在字幕安全框内
- [ ] 主版和剪短版都过了响度和安全框检查
